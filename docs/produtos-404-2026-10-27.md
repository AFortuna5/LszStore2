# Produtos cadastrados pelo admin retornando 404 — 27/10/2026

## Reprodução

O catálogo público contém slugs cadastrados manualmente com espaços e letras maiúsculas, como `Chinelo armani exchange` e `Moletom AX`.

Antes da correção, `/produto/Chinelo%20armani%20exchange` e `/produto/Moletom%20AX` retornavam HTTP 404. A API `/api/products/Chinelo%20armani%20exchange` encontrava o produto, e a página de um produto com slug separado por hífens retornava HTTP 200.

## Correção

- A consulta da página tenta primeiro o slug exato. Se não encontrar e o parâmetro contiver codificação percentual, tenta a versão decodificada uma vez.
- A busca exata tem prioridade para preservar slugs que contenham `%` literalmente. Uma codificação inválida retorna produto ausente sem lançar erro.
- `getProductPath` codifica o slug como um único segmento de URL e é utilizado pelos cards, carrossel, carrinho, URL canônica e sitemap.
- Os cadastros existentes são preservados. A correção não requer alteração no banco nem recadastro dos produtos.
- Testes de regressão cobrem espaços, acentos, caracteres reservados, porcentagem literal, parâmetros inválidos e produtos inexistentes.
